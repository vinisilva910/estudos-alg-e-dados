# Sistema de Busca Otimizado para Catálogo de Produtos - MegaStore

## Descrição
Sistema de busca eficiente utilizando tabelas hash para indexação rápida de produtos.

## Tecnologias
- Rust
- HashMap

## Como executar
```bash
cargo run
```

## Como testar
```bash
cargo test
```

## Exemplo
Busca por nome e categoria com retorno instantâneo.

## Arquitetura
- SistemaBusca
- Produto

## Estruturas de Dados
Uso de HashMap para acesso O(1).

## Desempenho
Alta performance mesmo com grandes volumes de dados.
